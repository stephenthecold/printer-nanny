{# ------------------------------------------------------- macOS installer -- #}
{{ c.section_title("macOS installer") }}

A bundle for {{ client.name }}: the client's wheels, its LaunchDaemon, and a freshly minted enrollment key — one per build, so revoking a leaked installer leaves every other install alone. Run ./build-macos-pkg.sh from the bundle on a Mac to produce the .pkg.

Central cannot finish the job itself: pkgbuild, productsign and notarytool exist only on macOS, and signing needs your own Developer ID certificate. An unsigned build is installable by MDM straight away; signing and notarizing is what makes it double-clickable for a human.

The bundle contains the enrollment key in a 0600 file. Treat the download as a secret — don't commit it or attach it to a ticket — and delete it once the .pkg is built.
